## Hello there

We are [SRDP Hub](https://srdphub.com), the creators of SRDP: the Single-Repo Data Platform. Our purpose is to create, promote and support standardised, vendor-neutral data infrastructures for the common good.

SRDP is a data platform with independent modules based on open standards.  It is a composable data stack based on the lakehouse architecture, orchestrated with Kubernetes into one cohesive network.

Any data. Anywhere.
